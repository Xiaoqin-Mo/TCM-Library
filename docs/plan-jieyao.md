## 3. 条目格式硬约束

- 目录：`library/fangji/jieyao/<方名拼音>/<方名拼音>_jieyao_001.md`；`id` = 文件名（全局唯一，
  与 jingfang/shifang 的 `<方名拼音>_001` 命名空间隔离）。
- Frontmatter 必填：`book: "方解（方论集要）"`、`chapter` = 剂型（如 "解表剂·方解"）、
  `section_title` = 方名+方义核心（如 "麻黄汤·开腠发汗宣肺平喘"）、`source_version`
  （注明所据方论，如「据《医方考》《医方集解》方论及《方剂学》教材方义要点归纳」）、
  `author`（如 "吴昆、汪昂等（方论集要）"）、`dynasty`（注明方源朝代，如 "汉"）、`type: fangji`、
  `conditions`（12 字段全为数组）、`weight: 8`、`tags`（含 "方解"）。
- `conditions` 填法：`fangming` 方名；`zhifa` 治法；`bingzheng` 主治病证；`zhengzhuang` 主症；
  `yaoming` 组成；`zhengxing` 证型；`keywords` 含方名、君臣佐使、类方比较关键词（如 "麻黄汤桂枝汤
  比较"）；无相关维度置 `[]`。
- 正文三层标记：`**【原文】**` = 方源与组成（引库内对应方条目要点，注明）+
  君臣佐使结构总述；`**【古注】**` = 历代方论要点（吴昆/汪昂等公有领域方论，忠实转述+出处）；
  `**【白话提要】**` = 非空：配伍机理白话解析 + 类方比较要点 + 使用注意（不承诺疗效）。
- 先例：`library/fangji/jingfang/`、`library/fangji/shifang/` 条目（frontmatter 结构、三层标记）。
