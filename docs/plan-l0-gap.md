## 背景：为什么需要本计划

L0（2025 药典药材）此前按不完整转录名单推进（旧 `herbs_l0.txt` 缺酸枣仁、蔓荆子、广藿香、磁石、老鹳草等大量药典常用药），导致：

1. L0 自身存在 **232 味**药典药材未收（其中 28 味为炮制品/加工品，并入基原药条目即可；**204 味**需新建条目）
2. 基于坏名单计算的 L1 差集（98 味初筛）失真，已弃用

2026-09-11 已从国家药监局官方 PDF（`raw/yaodian2025/herbs_l0.txt` 头注释含链接）重建 **614 味**权威名单，并经脚本核验：`官方 614 − 已写 408 = 缺口 232`，去炮制品后 **204 味净新增**。

## 批次推进规则（沿用用户既定节奏）

- 按功效类整类推进，**每批上限 50 条**（越少越好）
- 每条含：14 字段 frontmatter + 【原文】（据 2025 药典归纳，含基原/拉丁学名/药用部位/用法用量/注意）+【古注】（公有领域本草）+【白话提要】（简明 3-5 句 + 详解配伍宜忌）
- 有毒药（马钱子/狼毒/木鳖子/闹羊花/天仙子/罂粟壳/砒石/轻粉 等）必须写明限量、十八反十九畏、孕妇禁忌
- 每批一个 commit（`feat(library): add <cat> herbs batch N (M entries)`），一个 PR 回 dev
- 炮制品（制川乌/炙甘草/法半夏/鹿角胶/龟甲胶 等）并入基原药条目，不单独建条目
