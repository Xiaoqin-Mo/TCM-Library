# 标注指南 · TCM 检索基准金标准

> 适用范围：`benchmark/gold/annotation_batch*.csv` 的 relevance 列标注。
> 评分量表：0 / 1 / 2 / 3 四级（见下）。

## 1. 任务

对每条查询（`query_id`），判断候选条文（`candidate_id`）与该查询的**相关程度**。
判断标准是：**若用户提出此查询，这条条文能否作为有效检索结果呈现给用户？**

- 查询有三种形态（`query_form`）：
  - `modern` 现代术语（如「感冒」「失眠」）
  - `classical` 文言术语（如「太阳中风」「胸痹」）
  - `case` 临床案例式（如「咳嗽痰黄黏稠，咽喉肿痛，如何选药？」）

## 2. relevance 评分量表

| 分值 | 等级 | 定义 | 示例（查询「太阳中风」） |
| --- | --- | --- | --- |
| 3 | 高度相关 | 直接回答查询：方证/穴位/病证对应、条文即查询本身 | 「太阳之为病，脉浮，头项强痛而恶寒」桂枝汤证条文 |
| 2 | 相关 | 直接相关但不完整：同证型的不同方、相邻病证、治法相关 | 太阳伤寒条文（同为太阳病，非中风）；桂枝汤类方 |
| 1 | 弱相关 | 概念相关但不直接回答：理论解释、脏腑病机、邻近病证 | 六经辨证总论；风邪致病理论 |
| 0 | 不相关 | 与查询无语义关联，或仅字面偶然重合 | 不相关科目的条文 |

## 3. 标注原则

1. **以「能否作为检索结果呈现」为尺**，不以「是否完美」为尺——3 是直接回答，2 是有参考价值，1 是沾边但不够用。
2. **看查询意图，不看字面**：
   - 查询「足三里有哪些作用？」→ 足三里穴位主治条文 = 3；胃经循行 = 1。
   - 查询「咳嗽痰黄黏稠，咽喉肿痛，如何选药？」→ 清热化痰方药条文 = 3；风寒咳嗽方 = 0（反证）。
3. **白话提要与原文同等看待**：条文的白话提要已包含诊断要点/方证对应，按白话内容判断即可。
4. **不确定时取保守值**：介于两档之间时取较低档（宁可少标 3，不要误标 3）。
5. **医学免责**：本标注为信息检索相关性判断，不构成诊疗建议；条文本身已含「遵医嘱」提示。

## 4. 双人标注与 IAA

- 所有候选先由标注者 A 标注；
- 抽样 **20%** 查询由标注者 B 独立复标（同一 query+candidate 出现两次）；
- 跑 `python benchmark/merge_annotations.py` 计算 Cohen's κ；
- **κ < 0.6** 时：两人仲裁分歧 pair，按仲裁结果修正后重算；如实报告最终 κ 与仲裁比例。

## 5. 输出

- 在 `relevance` 列填 0/1/2/3；
- `notes` 列可选：标注理由（如「反证：风寒方不对应痰热」）；
- 保存 CSV（UTF-8），勿改列顺序与文件名。
