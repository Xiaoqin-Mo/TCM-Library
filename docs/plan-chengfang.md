## 3. 条目格式硬约束

- 目录：`library/fangji/chengfang/<制剂拼音>/<制剂拼音>_001.md`（与 shifang 同方名时用
  `<制剂拼音>_001` 即可，目录不同命名空间不冲突；若 id 全局冲突顺延 `_002`）。
- Frontmatter 必填：`id`（全局唯一）、`book: "《中国药典》一部/药品说明书（要点归纳）"`、
  `chapter` = 剂型（如 "解表剂/中成药"）、`section_title` = 制剂名+核心功效、`source_version`
  （注明依据，如「据现行版《中国药典》一部与药品说明书要点归纳」）、`author`（如
  "国家药典委员会等（要点归纳）"）、`dynasty: "当代"`、`type: fangji`、`conditions`（12 字段
  全为数组）、`weight: 8`、`tags`（含 "中成药"）。
- `conditions` 填法：`fangming` 制剂名；`zhifa` 功效；`bingzheng` 适应病证；`zhengzhuang` 主症要点；
  `yaoming` 组成药味（按说明书/药典，冷僻成分可列代表药味并注明「等」）；`keywords` 含制剂名、
  剂型、功效、OTC/处方属性；无相关维度置 `[]`。
- 正文三层标记：`**【原文】**` = 组成 + 功效主治 + 用法用量概要（要点归纳，注明依据）；
  `**【古注】**` = 留空标记（现代制剂无古注）或制剂源流一句；`**【白话提要】**` = 非空：
  适用情形、用法注意（**不承诺疗效**，标注「中成药，请按说明书或在医师指导下使用」）。
- 先例：`library/fangji/shifang/` 与 `jingfang/` 条目（frontmatter 结构、三层标记）。

## 4. 素材与内容纪律

- 依据《中国药典》一部成方制剂与现行药品说明书做**要点归纳并标注出处**；禁止整段转载说明书
  原文与受版权保护文本；剂量/用法用「按说明书」表述，不写具体处方。
- **不承诺疗效、不做个体化推荐**；对处方药标注「处方药，遵医嘱」；对品牌通名制剂不评
  疗效优劣。
- 无可靠公开依据（说明书/药典查不到）的制剂不收录。
