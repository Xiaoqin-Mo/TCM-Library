# plan-fbr.md · 中医条文级检索基准与分面桥接检索（FBR）研究计划

> 立项日期：2026-09-21；基线：`origin/dev`（3101 条，validate 0 错 0 警、回归 18/18、契约 0 错）。
> 本文件为 FBR 研究线的范围 / 阶段 / 验收权威计划：以 TCM-Library 为语料构建
> 可复现的中医条文级检索基准，提出以「分面层作古今桥」为核心的检索方法（FBR），
> 并定量回答古今语域鸿沟对检索 / RAG 的影响。每阶段完成回填「实际进度」。

## 1. 目标与完成标准

**一句话目标**：在 TCM-Library 上构建可复现的中医条文级检索基准，提出
分面桥接检索方法（Facet-Bridged Retrieval, FBR），形成「基准 + 方法 + 发现」
三件套，达到 SIGIR short/resource 或 CIKM/ECIR 投稿门槛。

**研究问题（RQ）**：

- **RQ1 语域鸿沟**：同一知识在文言（原文层）与白话（提要层）语域下，检索性能差多少？
  —— 利用三层平行结构做受控实验。
- **RQ2 分面桥**：以现代标准术语标注的分面层能否桥接古今术语鸿沟？软加权 vs 硬过滤，
  召回-精度权衡如何？
- **RQ3 语域路由**：按查询语域路由到不同层 / 融合，相比单层索引提升多少？
- **RQ4 端到端**：FBR 的证据供给对 RAG 答案质量（忠实度 / 准确率）的增益，相对基线检索器如何？

**验收红线**：

| 层 | 硬性指标 |
| --- | --- |
| 资源 | ≥300 查询；三形态（现代术语 / 文言术语 / 临床案例式）× 维度分层；多路 pooling + 双人标注；抽样 IAA Cohen's κ ≥ 0.6；库版本 pin 到 tag / commit |
| 方法 | 分面抽取 F1 ≥ 80%（受控词表约束内）；FBR 相对最强基线 nDCG@10 统计显著（配消融，不预设数值） |
| 发现 | 至少 2 个可写进结论的实证发现（方向性结论即可） |
| 可复现 | 全管线开源、零依赖可跑、评测 harness 与数据一起发布 |

## 2. 研究范围与产物

- **产物 1 · 检索基准**：查询集（300+，三形态 × 维度分层）、相关性金标准
  （pooling + 双人标注 + IAA）、评测 harness（Recall@k / nDCG@k / MRR + RAG 忠实度）。
- **产物 2 · FBR 方法**：
  - 组件 A：受控词表约束的分面抽取（LLM few-shot + 词表校验回退，报告抽取 F1）；
  - 组件 B：分面桥软加权融合（命中分面字段数 → 特异性桥接分，与 BM25 / 向量分融合）；
  - 组件 C：语域路由 / 层融合（现代查询 → 分面桥 + 白话层；文言查询 → 原文层）。
- **产物 3 · 实证发现**：register gap 定量、桥接增益、硬过滤 vs 软加权权衡、
  层选择策略、RAG 端到端结论。
- **二期（不在首发范围）**：创新点 3「平行层弱监督」——白话层与原文层为准平行对，
  自动生成跨语域训练信号微调稠密检索器（需 GPU）。

## 3. 方法设计与评测

- 检索通道：分面桥打分 ∥ 原文层 BM25 ∥ 白话层向量，融合排序（分面权重 × 层权重）。
- 基线清单：BM25（jieba 分词 / 不分词）、bge-m3 类中文向量、BM25+向量混合、
  LLM rerank、纯分面硬过滤。
- 消融矩阵：语料层（原文 / 古注 / 白话 / 拼接）× 检索器 × 分面（on/off）。
- 指标：Recall@10 / @50、nDCG@10、MRR；端到端加答 Faithfulness 与准确率。
- 注意：分面字段存在稀疏性（如《伤寒论》条文多缺 `yaoming`），须处理并如实报告
  「分面缺失时的表现」，可作为独立 finding。

## 4. 素材与纪律

- **固定库版本**：以 `dev` 当前 3101 条为语料基线，发布时 pin 到 tag / commit hash，
  基准与库版本绑定，保证可复现。
- **查询与金标准**：查询集为自建（标注者编写），术语引用受控词表；相关性由人工标注，
  标注指南随数据发布；LLM 辅助标注仅作效率工具，须报告人工复核比例。
- **数据发布**：与库同仓或独立数据集仓，MIT；标注指南与评测 harness 一并公开。
- **不承诺诊疗**：本线为信息检索研究，不构成诊疗建议；基准与论文须含医学免责声明。
- **分支规范**：每个逻辑单元一个分支（`docs/` 或 `feat/`）→ 一个 PR（base=`dev`）；
  严禁直接提交 `main` / `dev`；远程操作用 `gh`。

## 6. 风险与待定决策

**风险**：
1. 标注质量（人力已解决：可获取中医背景标注者）：仍须按标注指南双人标注 + 抽样 IAA，
   κ 不达标时扩大仲裁范围并如实报告。
2. 分面抽取 F1 不达标会稀释桥接增益——以词表约束 + 校验回退控制。
3. 基线过强导致增益不显著——本身可写成 finding（"retrieval doesn't help" 型结论），不算失败。
