## 3. 条目格式硬约束

- 目录：`library/linchuang/<科拼音>/<病证拼音>/<病证拼音>_001.md`（骨伤/五官/皮肤可平铺
  `<科拼音>/<病证拼音>/`，不分系统层）。
- Frontmatter 必填：`id`（与文件名同、全局唯一、先查占用冲突顺延 `_002`）、
  `book: "《中医外科学》等规划教材（要点归纳）"`（按科对应：外科学/妇科学/儿科学/骨伤科学/
  眼科学/耳鼻咽喉科学/皮肤性病学）、`chapter` = 科名（如 "外科"）、`section_title` = 病证名+
  核心病机、`source_version`（注明依据教材）、`author`（如 "教材编者（要点归纳）"）、
  `dynasty: "当代"`、`type: zhinan`、`conditions`（12 字段**全为数组**）、`weight: 8`、`tags`
  （含 "中医临床" 与科名）。
- `conditions` 填法：`bingzheng` 病证名；`zhengxing` 证型（如 乳痈·肝胃郁热）；`zhifa` 治法；
  `zhengzhuang` 主症；`fangming` 代表方（如 瓜蒌牛蒡汤）；`yaoming` 代表药；`keywords` 含病证名、
  科名、核心病机；无相关维度置 `[]`。
- 正文三层标记：`**【原文】**` = 定义 + 病因病机 + 辨证分型 + 治法方药（教材要点归纳+出处）；
  `**【古注】**` = 留空标记或经典条文；`**【白话提要】**` = 非空：诊断要点、分型简表、
  治疗原则与注意（**不承诺疗效**，标注「教材要点归纳，供参考；具体诊疗请遵医嘱」）。
- 先例：`library/linchuang/neike/feixi/chuanzheng/` 条目（type=zhinan、frontmatter、三层标记）。

## 4. 素材与内容纪律

- 依据《中医外科学》《中医妇科学》《中医儿科学》《中医骨伤科学》《中医眼科学》
  《中医耳鼻咽喉科学》《中医皮肤性病学》等规划教材做**要点归纳并标注出处**；
  禁止整段转载受版权保护文本。
- **不承诺疗效、不做个体化诊疗建议**；含毒剧药方（如雄黄、斑蝥）只列方名不展开用量；
  手术/急诊情形注明「须及时就医」。
- 无可靠教材/指南依据的病证不收录。
