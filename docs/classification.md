# 分类体系设计 · Classification

> 本文件是 TCM-Library 分类体系的**权威定义**。任何分类调整必须先改本文件
> （含 `scripts/tcm_lib.py` 中的 `CATEGORIES` 常量），保持二者同步。

## 1. 设计原则

1. **学科完备**：以现代中医学学科体系为骨架（基础理论 → 诊断 → 中药 → 方剂 → 针灸 → 临床 → 养生 → 医史），覆盖古籍与现代知识。
2. **古籍与学科双轨**：
   - 整本经典原文 → `jingdian/`（保持原文整本性，按篇/卷切条）；
   - 学科知识 → 各学科子类（方剂条目进 `fangji/`、单味药进 `zhongyao/`、腧穴进 `zhenjiu/`）；
   - 现代中医 → `xiandai/`（指南/共识/研究/教材）。
3. **路径即检索面**：`category/subcategory` 两级目录即第一层检索面，与 `conditions` 结构化字段互补。
4. **可扩展**：顶层分类保持稳定；子类可随收录扩展。

## 4. 目录归属规则

- 整本古籍原文 → `jingdian/<subcategory>/<book>/`（如 `jingdian/neijing/suwen/`），按篇切条。
- 单条方剂 → `fangji/<jingfang|shifang>/<book>/`。
- 单味药 → `zhongyao/yaowu/<book>/`。
- 腧穴 → `zhenjiu/shuxue/<book>/`。
- 古籍中的临床证治内容 → 依内容归入 `linchuang/` 相应子类。
- 现代文献 → `xiandai/<subcategory>/<book>/`。

**重叠处理**：同一知识在经典原文与学科条目中均可存在（如《伤寒论》原文在 `jingdian/shanghan/`，桂枝汤方剂条目在 `fangji/jingfang/`）。二者不互斥，检索时由 `weight` 与 `specificity` 排序区分。
