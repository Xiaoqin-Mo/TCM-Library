# 相关性标注指南（初稿）· TCM-Library 检索基准

> 计划：`docs/plan-fbr.md` · 协调：Issue #94 · 适用语料：全库 3101 条
> 状态：**初稿**——术语口径映射表（§3）待 @Xiaoqin-Mo 审阅补充后定稿；
> 本指南随仲裁理由持续更新（仲裁理由回写 §5）。

## 1. 任务定义

对「查询 × 候选条文」对打相关性等级（0–3），形成检索基准的相关性金标准。

- 查询分三种形态：**现代术语**（如"感冒发热恶风汗出，宜用何方？"）、
  **文言术语**（如"太阳中风，汗出恶风者，何以治之？"）、**临床案例式**（含四诊描述的病案）。
- 每条候选条文均附**原文、白话提要**两列，判断时两者都要看（白话层用于快速理解）。

## 2. 相关性等级（0–3）

| 等级 | 名称 | 判断标准 | 示例 |
| --- | --- | --- | --- |
| 3 | 高度相关 | 条文**直接回答**查询：证型 / 治法 / 方药 / 症状与查询核心意图一致 | 查询"感冒发热恶风汗出宜用何方" ↔ 伤寒论第13条（太阳中风桂枝汤证，条文直书"桂枝汤主之"） |
| 2 | 相关 | 与核心意图相关、可支撑**部分**回答，但不是直接答案 | 查询"外感风寒有哪些解表药可用" ↔ 白芷条目（单味药，属解表药范畴，支撑部分回答） |
| 1 | 边缘相关 | 仅术语 / 背景沾边，不支撑回答 | 查询"感冒用何方" ↔ 仅提到"感冒 / 解表"的泛论或药物条目 |
| 0 | 不相关 | 与查询无关 | 查询"感冒用何方" ↔ 《素问·上古天真论》（论养生，与感冒无涉） |

**判断顺序**：先看白话提要理解条文 → 对照查询核心意图 → 判断是否"直接回答 / 部分支撑 / 仅沾边 / 无关"。

## 3. 术语口径（古今映射规则）——初稿，待审阅

**原则：现代病名 / 证名与古籍相应概念视为同一对象时，判相关。**

- **R1 病名映射**：感冒 ↔ 太阳中风 / 伤寒；糖尿病 ↔ 消渴；便秘 ↔ 不大便、大便难；（待补充）
- **R2 症状映射**：发热 ↔ 翕翕发热、身热；恶寒 ↔ 啬啬恶寒；恶风 ↔ 淅淅恶风；（待补充）
- **R3 方名 / 药名**：以古籍原名为准（桂枝汤、芍药）；同一药物的古今别名视为同一（口径待定）
- **R4 部分重叠**：仅部分症状 / 术语重叠但病机不同 → 最高给 **2**
- **R5 拿不准**：标 **1** + 备注"存疑"，交仲裁；不自行硬猜

> 映射表最终以 @Xiaoqin-Mo 审阅版为准；本表为待补充的起点。

## 4. 操作流程

1. 接收 CSV 批次（每批约 **2 小时**工作量，约 40–60 查询，可拆半批）；
2. 逐行判断：只看「查询 + 候选条文」两列信息（原文 / 白话均已提供）；
3. 填写 `relevance`（0–3）；任何疑问写入 `notes`；
4. 整批完成后回传 CSV（发 Issue #94 或私聊）；
5. 仲裁后有等级调整的，按仲裁结果更新并回填理由。

## 5. 一致性（IAA）与仲裁

- 同一查询集由两位标注者**独立**完成；抽样计算 **Cohen's κ，目标 ≥ 0.6**；
- 分歧条目（两人等级不一致）与存疑条目由 **@Xiaoqin-Mo 仲裁**；
- 仲裁理由**回写本指南**，让口径持续收敛（前期仲裁多，越往后越少）。

## 6. 常见问题

- **Q：古文看不懂怎么办？** → 先看白话提要列；仍不明再对照原文，或标 1 + 备注。
- **Q：一条条文讲多个病机？** → 按查询核心意图判断是否被覆盖；部分覆盖最高给 2。
- **Q：时间不够？** → 每批可拆半批（约 1 小时），回传时注明即可。
