# Frontmatter 字段规范 · Entry Frontmatter Spec

> 每个条目 `.md` 以 YAML Frontmatter 开头，字段即检索引擎与 RAG 管线的索引结构。
> 机器契约见 `schema/frontmatter.schema.json`；受控枚举见 `schema/controlled_vocabulary.json`。

## 1. 条目文件模板

```markdown
---
id: "fj_guizhitang"            # 全局唯一，与文件名一致（不含 .md）
book: "伤寒论"                  # 典籍名 / 现代文献名
chapter: "辨太阳病脉证并治"      # 卷/篇/章名
chapter_num: 12                # 篇/章/条序号（可省略）
section_title: "桂枝汤方"        # 条目标题（中文）
source_version: "通行本"        # 版本出处
author: "张仲景"
dynasty: "汉"
type: "fangji"                 # 条目类型（见 §3）
conditions:                    # —— 中医结构化检索条件（RAG 核心）——
  zhengxing: ["太阳中风"]       #   证型
  zhifa: ["解肌发表"]           #   治法
  bingzheng: ["感冒"]           #   病症
  zhengzhuang: ["发热", "恶寒", "汗出"]  # 症状
  fangming: ["桂枝汤"]          #   方名
  yaoming: ["桂枝", "芍药", "甘草", "生姜", "大枣"]  # 药名
  xuewei: []                   #   腧穴
  jingluo: []                  #   经络
  siqi: []                     #   四气（药材条目用）
  wuwei: []                    #   五味（药材条目用）
  guijing: []                  #   归经（药材条目用）
  keywords: ["太阳病", "调和营卫"] #   开放主题词
weight: 8                      # 多书命中排序权重（见 §4）
tags: ["方剂", "经方", "解表剂"]
---

### 桂枝汤方

**【原文】**
桂枝三两（去皮）… 上五味，㕮咀三味，以水七升，微火煮取三升，去滓，适寒温，服一升。服已须臾，啜热稀粥一升余，以助药力。

**【古注】**
（如无可省略本层）

**【白话提要】**
本方为解肌发表、调和营卫的代表方……
```

## 2. conditions 字段（检索维度）

| 字段 | 含义 | 召回方式 | 示例 |
| --- | --- | --- | --- |
| `zhengxing` | 证型 | 精确交集 | 风寒束表、肝气郁结 |
| `zhifa` | 治法 | 精确交集 | 解表散寒、疏肝理气 |
| `bingzheng` | 病症 | 精确交集 | 感冒、消渴 |
| `zhengzhuang` | 症状 | 精确交集 | 发热、恶寒 |
| `fangming` | 方名 | 精确交集 | 桂枝汤 |
| `yaoming` | 药名 | 精确交集 | 麻黄、桂枝 |
| `xuewei` | 腧穴 | 精确交集 | 足三里 |
| `jingluo` | 经络 | 精确交集 | 手太阴肺经 |
| `siqi` | 四气 | 精确交集 | 寒、热、温、凉、平（药材条目） |
| `wuwei` | 五味 | 精确交集 | 酸、苦、甘、辛、咸（药材条目） |
| `guijing` | 归经 | 精确交集 | 肺经、膀胱经（药材条目） |
| `keywords` | 开放主题词 | 包含式召回 | 调护、禁忌、运气 |

**匹配语义**：跨字段 AND（查询的每个非空字段须与 entry 同字段有交集）、同字段多值 OR（任一值命中即算该字段命中）；
结果按「命中特异性 → weight → path」排序。`keywords` 单独做包含召回，不计入结构化特异性。

**填写要求**：
- 所有字段必填（空数组 `[]` 表示不适用）；新增字段须先更新 schema 与 `scripts/tcm_lib.py`。
- 结构化字段建议取受控词表（`schema/controlled_vocabulary.json`）内词，保证召回一致性；开放扩展新词时运行 `scripts/export_vocab.py` 同步词表。
- 字段值用**现代通行病名/证名**（如「感冒」而非「伤风」），古籍术语可并入 `keywords`。

## 4. weight 权重（多书命中降序展示）

| weight | 梯队 | 适用 |
| --- | --- | --- |
| 10–8 | 核心 | 内经、伤寒、金匮、本草经等经典原文；规划教材总论 |
| 7–5 | 重要 | 重要医家著作、常用方剂/药物/腧穴标准条目 |
| 4–2 | 拓展 | 专科参考、医案、歌诀、指南、研究综述 |
| 1–0 | 参考 | 附录、补遗 |

同书同条（多书命中）由 `specificity`（命中声明字段数）优先，再按 weight 排序。

## 5. 正文三层结构

```
**【原文】**     原文照录（古籍逐字，保留异体字；现代文献为原文/要点摘录）
**【古注】**     古注/校释/按语（可省略整层）
**【白话提要】** 白话转述：讲清本条「是什么 / 讲什么 / 怎么用」，面向检索可读性
```

- 三层标记为硬性要求：`validate_library.py` 校验三层标记存在且白话提要非空。
- 白话提要独立成层，供 RAG 语义检索直接消费；不得删除原文层。
